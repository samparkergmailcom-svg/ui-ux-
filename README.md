# Sam — Shoe Store UI/UX

A responsive shoe-shopping storefront built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive shoe store landing page
- Search/filter across shoe names and categories
- Four shoe product cards with pricing and discount labels
- Add-to-cart demo interaction
- Profile panel and demo login/logout flow
- Mobile bottom navigation

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Demo authentication
The login form is a front-end demo only. It stores the profile in the page while it is open and does not authenticate users or securely persist account data. Connect a real authentication provider before using this as a production store.

## GitHub Pages
To publish: open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub Pages will provide the public site URL once deployment finishes.
